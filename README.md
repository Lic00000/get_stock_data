Tesla Stock Analysis

Overview:
This project uses Python to analyse Tesla (TSLA) historical stock-price data. It explores stock returns, rolling 
averages, and volatility using financial data retrieved with the yfinance library.

Features:
* Retrieves historical Tesla stock-price data.
* Checks data types and missing values.
* Calculates simple and logarithmic returns.
* Compares cumulative simple and logarithmic returns.
* Calculates 20-day, 50-day, and 200-day rolling averages.
* Calculates rolling and annualised volatility.
* Visualises stock prices, moving averages, and volatility using Matplotlib.

Purpose:
This project was created to practise Python programming, data analysis, and basic financial mathematics 
using historical stock-market data.
